================================================================================
                            CONFIGURATION OPTIONS
================================================================================

ENABLE REAL BACKEND:
  1. Edit src/hooks/usePrediction.js line 7
  2. Change: const MOCK_MODE = false
  3. Set backend URL: const API_BASE = 'http://your-url/api'

ENVIRONMENT VARIABLES:
  Create .env file:
    VITE_API_URL=http://localhost:8000/api
    VITE_APP_NAME=Cloudify

CUSTOMIZE COLORS:
  Edit tailwind.config.js or use inline classes
  Available: sky, blue, purple, pink, green, red, etc.

ADJUST ANIMATIONS:
  Edit src/components/CloudBackground.css
  Change duration values (20s, 14s, 10s, etc.)
