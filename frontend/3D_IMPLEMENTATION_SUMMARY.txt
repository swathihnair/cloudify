COMPONENT: CloudBackground3D.jsx
-----------
Purpose: Render volumetric 3D clouds with smooth animations
Framework: React Three Fiber (@react-three/fiber)
Mesh Generation: @react-three/drei <Cloud/> component
Positioning: Fixed background (z-0, pointer-events-none)

CANVAS CONFIGURATION
---------
- Camera Position: [0, 0, 50]
- Field of View: 75 degrees
- Near Plane: 0.1
- Far Plane: 1000
- Clear Color: Transparent (0x000000, alpha=0)
- Antialiasing: Enabled
- Alpha: Enabled (transparent background)
- Power Preference: High performance

LIGHTING SETUP
---------
- Ambient Light: 1.5 intensity, #E8F3FF (sky blue)
- Directional Light 1: [20, 30, 20], 1.0 intensity, #D0E8FF
- Directional Light 2: [-20, 10, -30], 0.6 intensity, #B0D8FF
- Point Light: [0, 50, 0], 0.5 intensity, #E8F3FF

CLOUD CONFIGURATION (6 Clouds Total)
---------
Cloud 1: Position [-20, 15, -30], Scale 8, Speed 0.3, Opacity 0.4
Cloud 2: Position [25, 8, -25], Scale 10, Speed 0.2, Opacity 0.5
Cloud 3: Position [-15, -10, -20], Scale 9, Speed 0.25, Opacity 0.45
Cloud 4: Position [30, -5, -35], Scale 7, Speed 0.35, Opacity 0.38
Cloud 5: Position [-30, 20, -15], Scale 11, Speed 0.22, Opacity 0.55
Cloud 6: Position [10, -15, -28], Scale 8.5, Speed 0.28, Opacity 0.42

ANIMATION
---------
- Uses useFrame hook from react-three-fiber
- Clock-based timing for smooth motion
- Sine/cosine waves for natural drifting
- X-axis: ±8 units drift per cloud
- Y-axis: ±5 units drift per cloud
- Z-axis: ±6 units drift per cloud
- Speed varies per cloud (0.2 - 0.35)
- Offset timing prevents synchronization

================================================================================
                          TROUBLESHOOTING GUIDE
================================================================================

IF SCREEN IS BLANK:

1. Check WebGL Support
   - Open console (F12)
   - Type: new THREE.WebGLRenderer()
   - If error: WebGL not supported
   - Solution: Enable WebGL in browser settings

2. Check Network Tab
   - Look for failed requests
   - Verify all Three.js libraries loaded
   - Check Network Performance tab for CPU bottlenecks

3. Check Console Errors
   - F12 → Console tab
   - Look for red error messages
   - Common issues:
     a) "useFrame is not exported" → Fiber not loaded
     b) "Cloud is not defined" → @react-three/drei not loaded
     c) "WebGL context lost" → GPU driver issue

4. Try Full Rebuild
   - Stop dev server: Ctrl+C
   - Clear cache: npm cache clean --force
   - Reinstall: npm install
   - Restart: npm run dev

5. Check Hardware Support
   - Old GPUs may not support required features
   - Try disabling antialias: gl={{ antialias: false }}
   - Try reducing quality in browser settings

IF PERFORMANCE IS SLOW:

1. Reduce Clipping Planes
   - Current: near 0.1, far 1000
   - Try: near 1, far 100

2. Reduce Cloud Count
   - Current: 6 clouds
   - Try: 3 clouds (modify CloudScene)

3. Disable Antialiasing
   - gl={{ antialias: false }}

4. Lower Intensity Lights
   - Reduce intensity values by 50%

IF CLOUDS NOT VISIBLE:

1. Check Z-depth
   - Verify camera position: [0, 0, 50]
   - Clouds are at z: -30 to -35 (behind camera view)

2. Check Lighting
   - Ambient light should illuminate scene
   - Try increasing intensity to 2.0

3. Check Canvas Size
   - Verify Canvas fills viewport
   - Check style={{ width: '100%', height: '100%' }}

4. Check Color
   - Clouds are white (#FFFFFF)
   - Background is transparent (alpha=0)
   - May blend with page background
